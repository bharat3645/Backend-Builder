# blog-api (Go Fiber + GORM)

A comprehensive blog API with users, posts, and comments

Generated by [Backend Builder](https://github.com/bharat3645/Backend-Builder) from a DSL specification.

## Setup

```bash
cp .env.example .env
go mod tidy
go run main.go
```

## Docker

```bash
docker build -t blog-api .
docker run -p 8000:8000 --env-file .env blog-api
```
