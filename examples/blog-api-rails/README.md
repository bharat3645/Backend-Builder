# blog-api (Ruby on Rails API)

A comprehensive blog API with users, posts, and comments

Generated by InfraNest from a DSL specification.

## Setup

```bash
cp .env.example .env
bundle install
bin/rails db:create db:migrate
bin/rails server -p 8000
```

## Docker

```bash
docker build -t blog-api .
docker run -p 8000:8000 --env-file .env blog-api
```
